# slowapi: rate-limiter used to cap /api/auth/login to 5/min per IP
# (architecture review finding 1.2). Without this, an attacker who can
# reach port 80 can brute force the single admin user indefinitely —
# bcrypt slows each attempt (~0.1s) but there's no exponential backoff,
# no captcha, no throttle. slowapi also backs the optional API-wide
# rate limiter (Postgres-backed lockout row in `User.failed_attempts`).
